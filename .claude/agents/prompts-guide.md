# AI编程提示词指南

## 概述

本文档提供了Vue3项目开发中常用的AI编程提示词模板，帮助开发者更高效地与AI助手协作。

## 🎯 提示词分类

### 1. 组件开发提示词

#### 创建新组件
```
请创建一个Vue3组件：[组件名称]

要求：
- 使用Composition API和TypeScript
- 完整的Props接口定义和JSDoc注释
- 使用CSS变量进行样式定义
- 包含响应式设计
- 添加适当的事件处理
- 遵循项目编码规范

功能描述：[详细描述组件功能和交互]

参考现有组件：[相关组件路径]
```

#### 优化现有组件
```
请优化以下Vue3组件：[组件路径]

优化目标：
- [ ] 性能优化（减少重渲染）
- [ ] 类型安全（完善TypeScript类型）
- [ ] 可访问性（添加ARIA属性）
- [ ] 代码规范（ESLint规则遵循）
- [ ] 文档完善（JSDoc注释）
- [ ] 样式优化（使用CSS变量）

具体问题：[描述当前存在的问题]
```

### 2. API开发提示词

#### 创建API接口
```
请创建API接口：[接口名称]

接口规范：
- 请求方法：[GET/POST/PUT/DELETE]
- 请求路径：[API路径]
- 请求参数：[参数描述]
- 响应数据：[响应格式]
- 错误处理：[错误码和处理方式]

技术要求：
- 完整的TypeScript类型定义
- 统一的错误处理机制
- 请求/响应拦截器
- 加载状态管理
- 缓存策略（如需要）

参考现有API：[相关API文件路径]
```

#### API类型定义
```
请为以下API创建TypeScript类型定义：

API文档：[API文档链接或描述]

要求：
- 完整的请求参数类型
- 详细的响应数据类型
- 错误响应类型
- 泛型支持（如适用）
- JSDoc注释说明
- 与现有类型系统兼容

现有类型文件：src/interface/Api.ts
```

### 3. 状态管理提示词

#### 创建Pinia Store
```
请创建Pinia状态管理模块：[模块名称]

状态设计：
- 状态字段：[列出所有状态字段]
- 计算属性：[派生状态]
- 操作方法：[异步/同步操作]
- 持久化：[是否需要持久化]

技术要求：
- TypeScript类型定义
- 异步操作错误处理
- 加载状态管理
- 乐观更新策略
- 与API层集成

参考现有Store：src/store/modules/
```

### 4. 工具函数提示词

#### 创建工具函数
```
请创建工具函数：[函数名称]

功能描述：[详细描述函数功能]

技术要求：
- 纯函数设计（无副作用）
- 完整的TypeScript类型
- 边界条件处理
- 单元测试用例

- 性能优化考虑

使用场景：[描述使用场景和示例]
参考现有工具：src/utils/
```

### 6. 代码审查提示词

```
请审查以下代码的质量：[文件路径或代码片段]

审查维度：
- [ ] 代码规范（ESLint/Prettier）
- [ ] 类型安全（TypeScript）
- [ ] 性能优化
- [ ] 安全性检查
- [ ] 可维护性
- [ ] 可测试性
- [ ] 文档完整性

项目标准：
- 编码规范：.claude/agents/coding-standards.md
- 组件规范：.claude/agents/component-development.md
```

#### 架构设计审查
```
请审查项目架构设计：[模块或功能]

审查重点：
- [ ] 模块职责划分
- [ ] 依赖关系设计
- [ ] 扩展性考虑
- [ ] 性能影响评估
- [ ] 维护成本分析

架构原则：
- 单一职责原则

- 依赖倒置原则
- 接口隔离原则

参考文档：.claude/agents/project-structure.md
```

### 7. 重构优化提示词

#### 代码重构
```
请重构以下代码：[文件路径或代码片段]

重构目标：
- [ ] 提高代码可读性
- [ ] 减少代码重复
- [ ] 优化性能表现
- [ ] 增强类型安全
- [ ] 改善错误处理
- [ ] 提升可测试性

重构原则：
- 保持功能不变
- 渐进式重构
- 充分的测试覆盖
- 向后兼容考虑

现有测试：[相关测试文件]
```

#### 性能优化
```
请优化以下代码的性能：[组件或模块]

性能问题：
- [ ] 渲染性能（重复渲染）
- [ ] 内存泄漏（事件监听器）
- [ ] 网络请求（重复请求）
- [ ] 计算开销（复杂计算）
- [ ] 包体积（代码分割）

优化策略：
- Vue3响应式优化
- 组件懒加载
- 请求缓存机制
- 计算结果缓存
- 代码分割策略

性能基准：[当前性能指标]
```

## 🛠️ 提示词使用技巧

### 1. 上下文提供
- 总是提供相关的项目文件路径
- 包含现有代码示例作为参考
- 说明项目的技术栈和约束条件

### 2. 需求明确化
- 使用清单格式明确具体要求
- 提供详细的功能描述和边界条件
- 包含预期的输入输出示例

### 3. 质量标准
- 引用项目的编码规范文档
- 指定需要遵循的最佳实践
- 明确测试和文档要求

### 4. 迭代优化
- 基于AI输出结果进行针对性改进
- 提供具体的反馈和修改建议
- 逐步完善直到满足项目标准
